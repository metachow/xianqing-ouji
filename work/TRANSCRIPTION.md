# 《閒情偶寄》册一 录文规范

底本：北京大学图书馆藏康熙刻本，Internet Archive `02097225.cn`，扫描件 `scans/v1/02097225.cn_NNNN.png`
（1900×3000，300 dpi，黑白）。重排本**一页 = 原刻半叶**，逐行（每一行 = 原刻一行）与原刻对齐，
保留圈点和眉批。生成器按格子排字，所以录文必须**一字不多、一字不少、行款与原刻完全一致**。

## 文件

- 每幅扫描一个文件：`text/v1/NNN.txt`（NNN = 三位扫描号，如 `036.txt`）。UTF-8，无 BOM。
- 只写分给你的页码范围内的文件，以及你自己的笔记文件；不要改其他文件（工具、layout、别人的页）。
- 版面类型、行数、每行格数、半叶 a/b 面已在 `text/layout.yaml` 里：
  - preface（序）：5 行 × 12 字，写刻大字
  - toc（總目、卷一目次）：9 行 × 20 格
  - fanli（凡例）：8 行 × 18 字
  - body（卷一正文）：9 行 × 20 格。正文**低三格**（默认从第 3 格起，即每行 17 字）；
    部名（「詞曲部」）顶格，节名（「結構第一」）低一格，条目名（「戒諷刺」）看原刻实际位置。
- 如果某页的行数、格数与 layout 不符，不要改 layout，在笔记里报告。

## 格式（一行文字 = 原刻一行，从右往左依次写）

| 写法 | 含义 |
|---|---|
| `字。` | 该字右下的**小圈**（句读圈） |
| `字、` | 该字右下的**顿点**（短斜点、逗号形） |
| `字•` | 该字右下的**实心圆点**（U+2022；常见于密圈段落里的句末） |
| `{ … }` | **密圈**：花括号内每个字旁都有圈；其中句末的实心点照常写 `•` |
| `〔右半|左半〕` | **双行小注**（割注）：右半行、左半行；里面也可以有圈点 |
| `　` | 全角空格 = 一个空格子（行中空格、行首缩进以外的空位） |
| `^N ` | 行首：本行从第 N 格起（0 = 顶格）。不写就用该版面的默认缩进（body 为 3，其余为 0）。**负数 = 抬头**，高出版框（如 `^-1 聖主當陽`） |
| `@眉 K 甲乙丙|丁戊己|…` | **眉批**（框上小字）：K = 眉批第一行位于正文第 K 行之上；`|` 分隔眉批的各小行（从右往左），每小行从上往下 |
| `@版心 序|一` | 版心的卷次标签与叶码与 layout 默认不同时才写 |
| `@位 2.5 10.5 文字` | 自由定位：第 2.5 行（= 第 2、3 行之间）、从第 10.5 格起竖排（卷首署名之类） |
| `@無界 2` | 不画第 2、3 行之间的界栏 |
| `○` | U+25CB：**占一整格的大圈**（总目、引文之间的分隔圈）。不要用 〇（U+3007） |
| `# …` | 注释行（不排出） |

- 空行 = 原刻的一个空行（整行无字）。页末的空行可以省略。
- 密圈不跨页：本页若以密圈段落开头，第一行以 `{` 开始；本页结束时不必闭合。
- 一行内的字数 + 起始格 ≤ 版面格数，否则检查工具报错——这通常意味着漏行、串行或多字。
- 符号只用上表这几种。原文里没有任何现代标点；不要加。

## 圈点要看准

- 圈点都在字的**右侧**（偏下），即字与右边界栏之间。一个记号属于它**左边**那一行里、紧挨着它的那个字
  （同一行内，记号在字的右下 → 属于这个字）。
- 区分三种：空心小圈 `。`、实心圆点 `•`、斜短点 `、`。黑白扫描里小圈有时糊成实心或断开，放大看；
  拿不准就按文意（密圈段内句末多为实心点，普通段落的句读多为小圈）判断，并记在笔记里。
- 密圈段的起止要逐字核对：第一个带圈的字前写 `{`，最后一个带圈的字后写 `}`。

## 用字

- 用**繁体**（台湾/香港通行的 Unicode 码位），绝不用简体，也不要用日文新字形：
  `戶` 不是 `戸`，`說` 不是 `説`，`吳` 不是 `呉`，`黃` 不是 `黄`，`敎/教`、`爲/為` 照下一条处理。
- **原刻用的是有独立码位的异体字时，照录异体**：爲 眞 塡 徧 倣 旣 卽 敎 槩 畧 竝 緫 兩 㒺 等。之后会统一
  列表、由编者裁定是否改为通行字（`text/variants.tsv`），所以这里要忠实。
- 只是写刻笔形不同、没有常用独立码位的，录作通行繁体字。
- 不同的字不能互换：于/於、后/後、迺/乃、并/並、云/雲、余/餘、干/幹 都照原刻。
- 原刻明显错字、漫漶不清的字：照录（看不清的用最可能的字），记在笔记里，注明理由。
- 检查工具若提示「characters missing in the font」，说明该异体字字库里没有：改用通行字，并在笔记里写明原形。

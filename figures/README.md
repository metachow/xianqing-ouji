# 圖版與圖像

所有掃描影像取自哈佛燕京圖書館藏《閒情偶寄》康熙翼聖堂刻本
（HOLLIS 990080074400203941，IIIF manifest `https://mps.lib.harvard.edu/iiif/2/URN-3:FHCL:26853026`）。
哈佛圖書館對公有領域作品之公開數字影像不主張著作權，請求註明來源
（<https://library.harvard.edu/policy-access-digital-reproductions-works-public-domain>）。

## 插圖（`plates/`，為後冊居室部、器玩部預備）

做法：`tools/clean_plate.py OPENING SIDE NAME`。取藍色通道（黃紙在此通道偏暗，與背面透印的淺灰相近，
墨線則各通道皆黑），除以紙色背景（灰度閉運算），墨色濃於透印者為不透明（`--lo 0.45 --hi 0.80`），
去小斑點與觸及圖邊之頁緣、書口陰影，依投影找版框（含版心）裁切。輸出為原尺寸（約 300 dpi）透明底墨色圖層；
白底預覽在 `work/plates/`。原刻斷線、墨色深淺照舊，不補不修。
